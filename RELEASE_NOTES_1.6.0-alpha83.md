# Vector 1A 1.6.0-alpha83

This release adds a Custom spatial mode for 4-phase operation, built on alpha82.

- Shape four independent E1–E4 position curves using editable points, smooth or straight interpolation, and starting presets.
- Preview the curves and electrode output in an interactive 3D view while adjusting them live.
- Save and reload named Custom profiles with editable descriptions; saved profiles are available to compatible semantic integrations.
- Sharper curve and 3D previews, with a clearer profile naming field.
- Retains the alpha82 connection and layout improvements.

Download the Windows executable ZIP, extract the whole folder, and run the executable inside. Your settings and profiles stay in the profile folder beside the executable; they are not included in the release.

Custom profiles are exposed to semantic clients for selection; this release does not update external client applications.
